## Goal
Write a least-recently-used (LRU) cache class.

## Input
`class LRUCache` created as `LRUCache(capacity: int)`, with methods `get(key)`, `put(key, value)`, and support for `len(cache)` and `key in cache`.

## Requirements
1. `get(key)` returns -1 if the key is not in the cache.
2. `put(key, value)` stores the value, and a later `get(key)` returns it.
3. When a `put` adds a new key and the cache would go over `capacity`, remove the least recently used key first.
4. A successful `get(key)` counts as using that key (it becomes the most recently used).
5. `put` on a key that already exists updates its value and counts as using it; it does not evict anything.
6. If `capacity` is less than 1, raise a ValueError when the cache is created.
7. `len(cache)` returns the number of items currently stored.
8. `key in cache` returns True or False and does not count as using the key.

## Output
The `LRUCache` class. Respond with only Python code.
