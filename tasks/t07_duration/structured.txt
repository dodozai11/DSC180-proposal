## Goal
Write a function that converts a duration string such as "1h30m15s" into a number of seconds.

## Input
`parse_duration(s: str) -> int`

## Requirements
1. A duration is made of whole numbers each followed by a unit: h (hours), m (minutes), s (seconds). Return the total as an integer number of seconds (for example "1h30m15s" = 5415).
2. Each unit is optional, but the units that are present must appear in the order h, m, s (for example "45m" = 2700 and "2h5s" = 7205).
3. Units are case-insensitive (for example "1H2M" = 3720).
4. Ignore spaces anywhere in the string (for example "1h 30m" = 5400).
5. Raise a ValueError for anything that does not follow this format, such as unknown units ("5x"), a number with no unit ("5"), a unit with no number ("m5"), or units out of order ("30m1h").
6. Raise a ValueError if the string is empty or contains only spaces.

## Output
The total number of seconds as an int. Respond with only Python code.
