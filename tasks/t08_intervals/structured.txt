## Goal
Write a function that merges overlapping intervals.

## Input
`merge_intervals(intervals: list[list[int]]) -> list[list[int]]`
Each interval is a two-item list `[start, end]` of integers.

## Requirements
1. Merge intervals that overlap into a single interval (for example [[1, 4], [2, 6]] becomes [[1, 6]]).
2. Intervals that only touch also merge (for example [[1, 3], [3, 5]] becomes [[1, 5]]).
3. The input may be in any order; the result must be sorted by start value.
4. Do not modify the input list or the intervals inside it.
5. If the input is empty, return an empty list.
6. If any interval has a start greater than its end, raise a ValueError.

## Output
A list of [start, end] lists. Respond with only Python code.
