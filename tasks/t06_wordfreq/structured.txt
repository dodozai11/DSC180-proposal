## Goal
Write a function that counts how often each word appears in a text. Words are separated by whitespace.

## Input
`word_frequencies(text: str, top_k: int | None = None) -> list[tuple[str, int]]`

## Requirements
1. Count words case-insensitively and report each word in lowercase ("The" and "the" are the same word).
2. Remove these punctuation characters before counting: . , ! ? ; :
3. Return a list of (word, count) tuples.
4. Sort the list by count from highest to lowest; break ties alphabetically by word.
5. If `top_k` is given, return only the first `top_k` items of the sorted list; if it is None, return all of them.
6. If the text is empty or contains only whitespace, return an empty list.

## Output
A list of (word, count) tuples. Respond with only Python code.
