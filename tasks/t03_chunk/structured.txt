## Goal
Write a function that splits a list into chunks of a fixed size.

## Input
`chunk_list(items: list, size: int) -> list[list]`

## Requirements
1. Split `items` into consecutive chunks of length `size`, keeping the original order. Each chunk is a list.
2. If the length of `items` is not a multiple of `size`, the last chunk holds the leftover items and is shorter.
3. If `size` is less than 1, raise a ValueError.
4. If `items` is empty, return an empty list.
5. Do not modify the `items` list that was passed in.

## Output
A list of lists. Respond with only Python code.
